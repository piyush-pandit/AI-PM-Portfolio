# AI Product Management Portfolio

This is a working portfolio workspace for curating product-management case studies and project evidence, with a focus on user research, product strategy, analytics, and AI-enabled product thinking.

The portfolio is **not yet ready for public release**. Course handouts, raw assignments, and user-level analytics are kept locally and excluded from the parent Git repository by [`.gitignore`](./.gitignore). Only publish material you created or have permission to share, and review each case study for confidential or identifying information before adding it.

## Portfolio planning

- [`context.md`](./context.md) explains the portfolio goals, positioning, and suggested structure.
- [`read.me`](./read.me) provides the practical setup and content-curation guide.
- The hands-on memory game is maintained as a separate Git repository/submodule under [`Github_handson/memory-game-GHCP/`](./Github_handson/memory-game-GHCP/).

## Preview a future static site
